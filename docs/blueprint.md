# **App Name**: QATT (Quick ATTractions)

## Core Features:

- Attraction Recommendations: Suggest attractions based on user's location, available time, transportation, and preferences.
- Personalized Itineraries: Allow users to create custom travel itineraries by combining recommended attractions.
- Location Input: Enable users to input their current location or starting point.
- AI-Powered Recommendations Tool: Employ an AI tool to analyze user preferences and search history for personalized attraction suggestions, optimizing travel routes and considering budget limits. Recommendations are sourced from a combination of AI and external APIs or datasets.
- Category Filters: Implement filters to allow users to refine attraction searches by category (e.g., art, nature, history).
- Map Integration: Integrate a map using the Google Maps API (if cost-effective) to display attractions, routes, and travel times.
- User Profile: Collect email, name (optional), travel history, preferences, location, and photos for personalization, stored in a secure Firestore database.

## Style Guidelines:

- Primary color: A vibrant orange (#FF8C00) to evoke a sense of adventure and excitement.
- Background color: Light beige (#FAF0E6) for a clean and inviting backdrop.
- Accent color: A complementary blue (#4682B4) to highlight key elements and calls to action.
- Headline font: 'Playfair' (serif) for elegant headings; body text: 'PT Sans' (sans-serif) for readability. 
- Use clear and recognizable icons to represent different attraction categories and functionalities.
- Design a clean, map-centric interface with intuitive navigation and clear information hierarchy.
- Incorporate subtle animations for transitions and loading states to enhance the user experience.
